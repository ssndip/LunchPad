# Administrator's Guide

This guide covers the daily operations for managing the LunchPad system via the Manager Dashboard.

## 1. Menu Management
- **Adding Items**: Click "Add Item" in the Menu tab. You can specify names, prices, and categories.
- **Side Dishes**: You can configure items to require a side dish selection or include a default one.
- **Availability**: Toggle the "Available" switch to instantly hide/show items on the Kiosk.
- **Bulk Delete**: Use the "Clear All" option to reset the menu for a new day/week.

## 2. Card & RFID Management
- **Manual Add**: Enter the RFID and Owner name to create a new card.
- **Batch Import**: Use the "Batch Add" tool to paste comma-separated or space-separated lists (RFID, Name, PIN).
- **Balance Tracking**: View the total spending per card. Use "Reset All" to clear balances (e.g., at the end of the month).
- **Security**: Cards can be configured with an optional 4-digit PIN for extra security during ordering.

## 3. Order History
- The **History** tab provides a searchable list of all past transactions.
- Filter by date range, specific RFID, or owner name.
- View detailed item breakdowns for every order.

## 4. System Settings
- **Kiosk Toggle**: Open or close the kiosk for orders.
- **Test Mode**: Allows ordering without valid RFID cards (useful for debugging).
- **Localization**: Switch between English and Bulgarian.
- **Whitelist**: Restrict administrative access to specific RFID cards if needed.
- **PWA**: Enable/Disable the ability for users to install the app on their mobile devices.
