## $(date +%Y-%m-%d) - Added missing ARIA label to Cancel icon-button
**Learning:** Icon-only buttons (like the Cancel `Trash2` button in `CardsTab.tsx`) can sometimes have a `title` attribute for tooltips but still lack an `aria-label`, creating poor experiences for screen readers. Using localized strings (e.g., `t('modals.cancel')`) ensures consistency between hover states and screen reader announcements.
**Action:** Always search for `<button` elements containing only SVG icons (e.g., `Trash2`, `X`) and verify both `title` and `aria-label` are present and utilizing translation keys (`t(...)`).
