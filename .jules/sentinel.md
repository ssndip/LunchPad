## 2026-06-09 - Prevent AI API Key Leak
**Vulnerability:** The `GET /api/init` endpoint and WebSocket `INITIAL_STATE` broadcast exposed `settings.aiApiKey` in plaintext to unauthenticated clients. Furthermore, `fetchSettings` in the settings controller leaked the full AI API key to authenticated clients.
**Learning:** Returning full configuration objects directly to the frontend, even if primarily consumed by an admin dashboard, guarantees that sensitive variables like API keys are leaked if not explicitly filtered or masked. This creates a high-risk security vulnerability.
**Prevention:** Always mask sensitive variables (e.g., `aiApiKey: settings.aiApiKey ? '********' : ''`) in API responses and state broadcasts. In endpoints that update these configurations, explicitly ignore updates where the value equals the placeholder mask to avoid accidentally overwriting the valid secret in the database.
