## 2026-05-05 - Insecure Express CORS Handling
**Vulnerability:** A wildcard CORS configuration `app.use(cors())` was originally used, making the server open to cross-origin requests. An initial attempt to fix this returned an Error in the callback `callback(new Error('...'))` for invalid origins.
**Learning:** Returning an Error in the `cors` callback does not just reject CORS preflights; it gets passed down the Express `next(err)` pipeline, resulting in the server throwing 500 Internal Server Errors and potentially leaking stack traces or causing Denial of Service.
**Prevention:** Always fail securely by passing `false` to the callback (`callback(null, false)`) to block the origin without triggering Express error handling. Also, explicitly handle `null` or missing origins to prevent bypasses.
